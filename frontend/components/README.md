# Components

Componentes compartilhados para a modularizacao progressiva do frontend.

Objetivo:

- centralizar elementos reutilizaveis
- reduzir duplicacao entre modulos
- preservar a UI atual durante a migracao

Estado atual:

- a aplicacao ainda usa grande parte da logica legada em `frontend/assets/js/app.js`
- esta pasta foi preparada para absorver utilitarios e componentes reais de forma incremental
