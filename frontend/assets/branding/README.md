Coloque a logo oficial da empresa nesta pasta.

Arquivo recomendado para uso automatico na tela de login:

- `logo-empresa.png`

Tambem pode usar:

- `logo-empresa.svg`
- `logo-empresa.jpg`
- `logo-empresa.webp`

Prioridade atual no login:

1. Logo salva nas configuracoes comerciais do sistema
2. Arquivo local `./assets/branding/logo-empresa.png`

Se quiser usar outro nome de arquivo como padrao automatico, ajuste em `app.js`.
